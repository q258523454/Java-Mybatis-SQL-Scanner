# Privacy Policy — MyBatis SQL Scanner AI

Effective date: 2026-11-15

## What we collect

We do not collect any telemetry, usage data, or personal information.

## Local scanning

Static scanning runs entirely on your machine. Project files, source code, and mapper XML are never uploaded.

## Ask AI

The Ask AI feature sends only SQL context to the AI provider you configure:

- the raw XML fragment of the scanned SQL
- the formatted SQL text
- the SQL type
- the scan engine's error/suggestion text

You choose the provider (DeepSeek, Qwen, Doubao, GLM, Kimi, GPT, Claude, or a custom endpoint). No other project files, source code, or personal data are sent.

## API Key storage

Your API Key is stored encrypted in a local IDE configuration file. It is used only to authenticate requests to the provider you selected and is never sent to us.

## Your responsibility

SQL text may contain business-sensitive information. Review it before enabling Ask AI, and use a private or self-hosted endpoint where required.
